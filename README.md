# SMS Spam Classification using SVM

## Overview
This project classifies SMS messages as **ham** (normal) or **spam** using TF-IDF text features and a Linear Support Vector Machine (SVM).

## Dataset
Use the [SMS Spam Collection dataset on Kaggle](https://www.kaggle.com/datasets/uciml/sms-spam-collection-dataset). Download the CSV and upload it when prompted by the notebook. The notebook checks that the dataset contains the expected `v1` and `v2` columns.

## Method
1. Inspect the dataset and remove duplicate messages.
2. Clean message text and map labels (`ham` → 0, `spam` → 1).
3. Split data into training and test sets using stratification.
4. Convert text to TF-IDF features using unigrams and bigrams.
5. Train a baseline Linear SVM.
6. Tune the SVM `C` parameter using stratified 5-fold cross-validation, optimizing F1-score.
7. Evaluate the tuned model on the held-out test set using accuracy, precision, recall, F1-score, a classification report, and a confusion matrix.
8. Demonstrate predictions on sample messages.

## Improvements made
- Fixed the mismatch between the documented CSV filename and the hard-coded filename by detecting the uploaded CSV automatically.
- Added input validation for the expected dataset columns.
- Used a broader `C` search range (`0.01`, `0.1`, `1`, `10`, `100`).
- Selected hyperparameters using F1-score rather than the default accuracy score.
- Used stratified cross-validation with shuffling and a fixed random seed.
- Reported performance on a held-out test set after tuning and added a confusion matrix.

## How to run
1. Open `SMS_Spam_SVM_Improved.ipynb` in [Google Colab](https://colab.research.google.com/) or Jupyter.
2. Run all cells from top to bottom.
3. Upload the downloaded dataset CSV when prompted.
4. Review the actual scores and confusion matrix generated by your run.

## Metrics
- **Accuracy:** fraction of all predictions that are correct.
- **Precision:** fraction of messages predicted as spam that really are spam.
- **Recall:** fraction of actual spam messages detected.
- **F1-score:** harmonic mean of precision and recall.
- **Confusion matrix:** shows correct and incorrect predictions for ham and spam.

## Limitations
- The model is trained on a particular SMS dataset; its performance may differ on newer messages or other languages.
- Removing digits and punctuation during preprocessing may discard useful spam clues.
- Sample predictions are demonstrations; the held-out test metrics provide a more meaningful evaluation.

## Reproducibility
The split and cross-validation strategy use fixed random seeds. Run the notebook to generate results in your environment; do not report metrics that you have not verified.
